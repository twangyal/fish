# Completion Gates

Before the Lead declares a non-trivial task complete:

- [ ] Architect investigation completed
- [ ] implementation scope accepted by Lead
- [ ] Builder implementation completed
- [ ] relevant tests added or updated where warranted
- [ ] Builder verification succeeded
- [ ] Reviewer completed independent review
- [ ] all blocking review findings resolved
- [ ] Verifier independently ran required checks
- [ ] no legitimate test was weakened merely to obtain green
- [ ] documentation updated where required
- [ ] project state/handoff updated where required
- [ ] Lead inspected the completion evidence

A task with unresolved blocking review findings is not complete.

A task with failed required verification is not complete.

A task with required checks that were not run must explicitly remain partially unverified.
